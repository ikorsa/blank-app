# Каштан — пример лендинга частного детсада (СПб)

Демо-сайт вымышленного частного детского сада **«Каштан»** на Петроградской стороне Санкт-Петербурга.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
cd kindergarten-spb
python3 -m http.server 8080
```

Страница: http://localhost:8080/

## Состав

- `index.html` — одностраничный лендинг
- `css/styles.css` — стили и анимации
- `js/main.js` — шапка при скролле и демо-форма заявки

Форма экскурсии никуда не отправляет данные — это только пример интерфейса.
